# AICTE OneView

Project root contains the Angular frontend in `frontend/` and FastAPI backend in `backend/`.

- Frontend: open a terminal in `frontend/`, run `npm ci`, then `npm start`.
- Backend: open a terminal in `backend/`, create/activate a Python virtual environment, install dependencies from its requirements file if present, configure environment variables, then run the command in `backend/README.md`.
- `.gitignore` is at the project root.

Angular build, PostgreSQL integration, and the full end-to-end workflow have not yet been verified.
