# AICTE OneView Angular Frontend

This is a complete Angular CLI workspace including the dashboard UI.

## Requirements
- Node.js 20.19+ or 22.12+ recommended for Angular 21
- npm

## Run
Open PowerShell in this `frontend` folder:

```powershell
npm install
npm start
```

Open http://localhost:4200.

Build:
```powershell
npm run build
```

## Important
- The dashboard currently uses illustrative in-memory sample data.
- It is not connected to the FastAPI backend yet.
- Replace demo records with API responses in the integration step.
